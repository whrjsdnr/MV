# 추가 계산 범위와 이유

기존 결과·원본·전체 해상도 계산은 변경하지 않는다. 이번 추가 계산은 다음으로 제한한다.

1. 기존 CSV의 전수 재집계: 메타데이터, 배경/영역별 밝기, 마스크 연결, 박스, 시점 비교. JPG 디코딩이나 해상도 지표 재계산을 수반하지 않는다.
2. CenterCrop의 정확한 결함 픽셀 보존율: 기존 결과에는 중앙 사각형별 픽셀 교집합이 저장되어 있지 않다. 따라서 제공 PNG **51,329개만 읽어** 검증된 `gray>0` 정책으로 1024 전체 및 896/768/640 중앙 사각형과의 교집합을 계산한다. JPG 전수 재처리는 하지 않는다. 빈 제공 마스크는 별도 상태로 남기고, 마스크 없는 NG는 이 분모에 포함하지 않는다. 이 추가 분석은 결함 이미지 단위의 완전 제거/부분 잘림을 측정하며 실제 물리 결함 수와 구분한다.
3. 기존 60,629개 XYXY 박스는 CSV에서 중앙 Crop과의 기하학적 교집합 및 마지막 Resize 좌표를 계산한다. Crop 후 박스 면적 비율은 결함 픽셀 보존율과 다르다. 클리핑 후 0면적은 유효 박스로 내보내지 않는다. NG 라벨은 유지한다.
4. 기존 30품목×5시점×OK/NG 대표 표본 **300장**만 동일 전경 알고리즘으로 다시 추정하여 중심·외곽 여백·Crop 후 점유율을 조사한다. 기존 결과에는 제품 마스크와 중심 좌표가 저장되지 않았다. 품질 조건을 통과한 표본만 기하 통계에 쓰고 불확실 표본은 결측으로 남긴다. 수작업 정답 분할이 없어 제품 보존 정확도는 UNVERIFIED이며 전수 제품 위치 분석은 NOT_ANALYZED다.
5. 12개 모델의 공개 소스·설정만 다운로드하여 커밋/함수/행 근거를 보존한다. 소스는 실행하지 않으며 모델·가중치·추가 데이터셋은 다운로드하지 않는다.

새 결과는 `outputs/preprocessing_review_20261112_v1/`, 소스 조사 근거는 `outputs/model_sources_20261112_v1/`에 기록한다. 기존 산출물이 있으면 중단하거나 체크포인트에 이어서 수행한다. 외부 검토 패키지는 원본 영상·마스크·영상이 포함된 파생 사례와 개인 경로를 제외하고 상대 경로만 사용한다.
